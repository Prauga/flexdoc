# FlexDoc package release 3.5.0

FlexDoc **3.5.0** publishes the Node disagreement loop. Package semver stays independent of product-milestone labels.

## Package versions

- `@prauga/flexdoc-client` — **3.5.0**
- `@prauga/flexdoc-backend` — **3.5.0**
- `@prauga/flexdoc-cli` — **0.8.0**

`@prauga/flexdoc-core` and the native adapter lines are unchanged. This wave does not change their behavior. Examples and the install tables stay on the artifacts a user can install today, and move to these versions in the post-publish repin.

## What changes for an existing Node service

When runtime discovery is complete, an implemented route that OpenAPI does not document is an error. `flexdoc validate` exits 1 and names the method and path. Partial discovery keeps that finding a warning. A check that previously passed because the only disagreement was that warning now fails.

`runtimeIntelligence.acknowledgedUndocumented` marks a chosen route as acknowledged info. The route remains in the runtime record, `summary.runtime` still counts it, and the acknowledgement does not fail validation.

Opening the finding shows the missing contract beside the registered method and path. The API Client can send that route. The URL uses the snapshot `serverOrigin` when the runtime reported one, and is a same-origin path otherwise. The request prefers the API host only when host execution is available and the server has not set `preferHostExecution` to false.

The page does not invent a handler, a schema, parameters, or auth for a route the contract does not declare.

## Host execution

The `@prauga/flexdoc-backend` **3.5.0** host-execution contract is unchanged from 3.4.0. [`docs/host-execution-operations.md`](../host-execution-operations.md) still describes that contract.

## Release sequencing

This wave uses the version contract's in-flight window. Source versions for the client, backend, and CLI sit ahead of the registry. After those three artifacts exist, the follow-up repin updates examples, generated lock metadata, and the published baselines, then clears `pending`.
